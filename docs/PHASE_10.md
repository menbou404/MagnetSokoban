# PHASE_10.md

## 目的

箱の向きを変える最初の正式ギミックとして、回転床を追加する。

回転床は磁力ギミックではなく、箱が移動先マスへ入った直後に向きを変える床として扱う。

## 正式仕様

- 回転床は、箱がそのマスへ入ったときに箱の向きを 90 度回転させる床である
- 右回転床と左回転床を実装する
- プレイヤー自身は回転しない
- 回転は論理状態として即時に確定する
- 処理順は、プレイヤー移動または押し、箱の移動確定、回転床による向き更新、磁力処理の順とする
- つまり、回転してから磁力が出る

## 回転定義

右回転:

- 上 -> 右
- 右 -> 下
- 下 -> 左
- 左 -> 上

左回転:

- 上 -> 左
- 左 -> 下
- 下 -> 右
- 右 -> 上

## レベル文字

- `]`: 右回転床
- `[`: 左回転床

既存の箱向き文字、壁、床、ゴールと衝突しない文字として採用する。

## 責務

- `GameState.gd`: 回転床の位置と種類を保持する
- `LevelLoader.gd`: レベル文字から回転床を読み込む
- `MoveResolver.gd`: 箱移動確定後、磁力処理前に回転床を適用する
- `BoardView.gd`: 回転床を表示するが、ルール判定は持たない
- `MagnetResolver.gd`: 回転床ロジックを持たない
- `Main.gd`: 回転床ロジックを持たない

詳細な履歴管理用マイルストーンは `docs/milestones/PHASE_10_ROTATION_GIMMICK.md` も参照する。
