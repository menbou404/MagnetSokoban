# レベルデータ形式.md

## 目的

PHASE_07 で使用する外部レベルファイルの最小形式を定義する。

この形式は、既存の `LevelLoader.gd` が扱っている行文字列表現を `levels/` 配下へ移すための暫定形式である。
本番形式や `.tres` への移行は後続フェーズで検討する。

## 配置

確認用レベルは `levels/test/` に置く。

プレイ用レベルは `levels/play/` に置ける構造だけを用意する。

レベルの順序、分類、表示名、ファイルパスは `levels/level_catalog.json` で管理する。

## レベルファイル

1 レベル 1 ファイルとし、拡張子は `.lvl.json` とする。

最小項目は以下。

- `id`
- `name`
- `purpose`
- `rows`

例:

```json
{
  "id": "basic_push_01",
  "name": "01 Basic Push",
  "purpose": "basic move, box push, clear, undo, reset",
  "rows": [
    "########",
    "#......#",
    "#.P>G..#",
    "#......#",
    "########"
  ]
}
```

## rows の文字

PHASE_07 では既存の `LevelLoader.gd` の行文字列表現をそのまま使う。

- `#`: 壁
- `.`: 床
- `G`: ゴール
- `P`: プレイヤー
- `+`: ゴール上のプレイヤー
- `>` / `R`: 右向き箱
- `<` / `L`: 左向き箱
- `^` / `U`: 上向き箱
- `v` / `V` / `D`: 下向き箱
- `1` から `5`: 強さ付き右向き箱
- `n`: ゴール上の右向き箱
- `s`: ゴール上の左向き箱

## カタログファイル

`levels/level_catalog.json` は、レベル内容そのものではなく、読み込み順と分類を管理する。

最小項目は以下。

- `default_group`
- `levels`

`levels` の各要素は以下を持つ。

- `id`
- `name`
- `group`
- `path`
- `purpose`

例:

```json
{
  "default_group": "test",
  "levels": [
    {
      "id": "basic_push_01",
      "name": "01 Basic Push",
      "group": "test",
      "path": "res://levels/test/basic_push_01.lvl.json",
      "purpose": "basic move, box push, clear, undo, reset"
    }
  ]
}
```

## 責務

`LevelLoader.gd` が JSON と `rows` を解釈する。

`Main.gd` は現在のレベルインデックスとカタログ entry だけを扱い、レベル本文を持たない。

`BoardView.gd` と resolver はレベルファイル形式を知らない。
