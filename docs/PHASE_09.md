# PHASE_09.md

## 目的

通常押しルールを拡張し、隙間なく連続する複数の可動箱を 1 つの押し列として 1 マス押せるようにする。

この追加は磁力ギミックではなく、`MoveResolver.gd` が担当する通常移動ルールとして扱う。

## 正式仕様

- プレイヤーが押した方向に、隙間なく連続する可動箱がある場合、それらを 1 つの押し列として扱う
- 押し列の先頭のさらに 1 マス先が空なら、列全体を同方向へ 1 マス移動する
- プレイヤーは最初の箱の元位置へ移動する
- 押し列の先頭の次マスが壁、盤面外、他物体、または非可動物体なら押しは成立しない
- 空きマスをまたいだ先の箱は同じ押し列に含めない
- 通常押しの解決が先で、その後に磁力処理へ進む
- 押しで同時に動いた箱はすべて一次起点候補になる
- 一次起点候補は同じ段階で評価する
- 一次起点候補から生じる複数の磁力作用候補は、既存の強い磁力優先と同強度時の同時処理で解決する

## 責務

- `MoveResolver.gd`: 押し列の探索、成立判定、逆順移動、一次起点候補 id の作成
- `MagnetResolver.gd`: 一次起点候補集合の同段階評価、磁力作用候補の解決、連鎖処理
- `Main.gd`: 接続の司令塔に留め、押し列ロジックを持たない
- `BoardView.gd`: 表示に留め、押し列ルールを持たない

詳細な履歴管理用マイルストーンは `docs/milestones/PHASE_09_BASICPUSH.md` も参照する。
