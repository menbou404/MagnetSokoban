# PHASE_11.md

## 目的

固定磁石ギミックを追加し、盤面上に移動しない磁力物体を置けるようにする。

固定磁石は箱と同じく向きと強さを持つが、押しても磁力でも動かない物体として扱う。

## 予定仕様

- 固定磁石は 1 マスを占有する
- 固定磁石はプレイヤーも箱も通行できない
- 固定磁石は押せない
- 固定磁石は通常押し列に含めない
- 固定磁石は磁力判定の対象になる
- 固定磁石は向き、面ごとの極、強さを持つ
- 箱と固定磁石の相互作用では、動ける箱だけが移動対象になる
- 固定磁石自身は連鎖起点にならない
- 固定磁石との相互作用で動いた箱は、次の連鎖起点候補になってよい
- 回転床で向きが変わった箱は、その向きで固定磁石に反応する

## 処理順

1. プレイヤー移動または押しを解決する
2. 必要なら回転床を適用する
3. その後で磁力処理へ進む
4. 固定磁石を含む磁力判定を行う

## 責務

- `MagneticBodyState.gd`: `kind` と `movable` で固定磁石を表現する
- `GameState.gd`: 固定磁石を磁力物体として保持する
- `LevelLoader.gd`: レベルファイルから固定磁石を読み込む
- `MoveResolver.gd`: 固定磁石を押せない非可動物体として扱う
- `MagnetResolver.gd`: 固定磁石を磁力対象にし、可動側だけを移動対象にする
- `BoardView.gd`: 固定磁石を箱と区別して表示する
- `Main.gd`: 固定磁石ロジックを持たない

詳細な履歴管理用マイルストーンは `docs/milestones/PHASE_11_FIXED_MAGNETS.md` も参照する。
