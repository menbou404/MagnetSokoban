# PHASE_05_GAMEPLAY_CONTENT.md

## フェーズ名

ゲームプレイ成立とコンテンツ整備

## 目的

プレイ可能な最小セットとして、見た目、テスト面、基本的な遊びの成立を整える。

## 実装状況

2026-05-03 に最小実装済み。
確認面は `Main.gd` 内のレベル配列として暫定管理する。
本番用レベルデータ形式は未確定のため、今後のフェーズで検討する。

## 確認面

1. `01 Basic Push`: 基本移動、箱押し、クリア、Undo、Reset
2. `02 Attraction`: 引力と同強度時の同時移動
3. `03 Repulsion`: 反発と強さ差による優先処理
4. `04 Chain`: 磁力で動いた箱を起点にする連鎖
5. `05 Direction Check`: 上下左右の向き表示と強さ表示

## 対象

- 箱の向きが見える表示
- テスト面の整備
- クリア確認
- 巻き戻し確認
- 最低限の遊びやすさの調整

## 完了条件

- 3 つ以上のテスト面がある
- 箱の向きと強さが視覚的に分かる
- クリアまで一通り遊べる
- 巻き戻しとリセットが安定する
