# PHASE_03_MAGNET_CORE.md

## フェーズ名

磁力コア実装

## 目的

押した直後にだけ発動する、強さと距離を持つ磁力連鎖の最小版を実装する。

## 対象

- 起点処理
- 直線探索
- 距離判定
- 引力 / 反発判定
- 連鎖キュー処理
- 「同じ起点は 1 手で 1 回だけ」の暫定ルール

## 完了条件

- 押された箱を最初の起点にできる
- 直線上の最初の対象だけを見る
- `source.strength + target.strength >= distance` で発動判定できる
- 引力 / 反発が 1 マス単位で動作する
- 連鎖が停止するまで進む
- 同じ起点の再処理を防げる

## 未解決論点

- 無限ループ検知の正式仕様
- 起点ごとの処理方向の最終設計
