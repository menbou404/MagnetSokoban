# PHASE_06_ANIMATION_READABILITY.md

## フェーズ名
アニメーションによる可読性改善

## 状態
最小実装完了。  
`TurnResult` / `ActionEvent` / `AnimationDirector` を導入し、イベント列ベースのアニメーション再生と再生中の入力停止を実装済み。
次は Godot エディタ上で実プレイ確認を行い、PHASE_06 の範囲内で視認性を確認する。

## 目的
1 手の中で起きた因果関係をプレイヤーが理解できるように、イベント列ベースのアニメーション再生を導入する。

## 背景
現状では、プレイヤー移動、箱押し、磁力発動、連鎖、同時処理が瞬時に起こるため、何が原因で何が起きたのかが追いづらい。  
特に磁力ゲームでは、可読性がゲーム体験そのものに直結する。

- `ActionEvent` 相当の導入
- `AnimationDirector` 相当の導入

- 同時処理の同時再生
- 再生中の入力停止

## 完了条件
1. プレイヤー移動が視認できる
2. 箱移動が視認できる
3. 磁力発動の予告が視認できる
4. 連鎖順が追える
5. 同時処理が同時に見える
6. 再生中は入力が停止する
7. 論理状態と表示状態が分離されている
8. Main にアニメーションロジックが集中していない
9. Resolver に Tween や待ち時間が入っていない
10. 既存のゲームルールを壊していない
